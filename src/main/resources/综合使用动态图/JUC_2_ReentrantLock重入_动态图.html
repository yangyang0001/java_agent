ReentrantLock：可重入计数与公平 / 非公平

    要点
    
    
      
      
    • 可重入：已经持有锁的线程再次获取同一把锁可以直接成功，避免自己和自己死锁（如递归调用加锁方法）。
      • 
      
    • 实现：lock 时 state == 0 → CAS 设为 1 并记录 owner；state != 0 且 owner 是当前线程 → state + 1（重入，直接 setState，无需 CAS）。
      • 
      
    • unlock 时 state - 1，减到 0 才真正释放（owner 置 null）并唤醒后继。所以 lock 了几次就必须 unlock 几次，unlock 要放在 finally 中。
      • 
      
    • 公平 / 非公平：非公平锁（默认）获取时先直接 CAS 抢一次；公平锁先通过 hasQueuedPredecessors() 判断队列中有没有人在排队。
      • 
      
    • synchronized 也是可重入的，靠 ObjectMonitor 中的 _recursions 计数。
      •
