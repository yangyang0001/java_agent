OOP-Klass 二分模型：对象只存数据，类元数据只存一份

HotSpot 用两部分表示一个 Java 对象：堆里的 OOP（对象头 + 实例字段，每个对象一份），和元空间里的 Klass（字段布局、方法、vtable、常量池，每个类一份）。对象头里的类型指针把两者连起来；java.lang.Class 对象是 Klass 在堆里的镜像（mirror）。

栈、堆与元空间

本步变化 / 访问路径 Class 镜像（mirror） Klass 元数据

按 JDK 8 HotSpot 画出，开启压缩类指针时类型指针占 4 字节，Klass 位于元空间中的压缩类空间。箭头是指针，移动的圆点是一次访问的路径。

    要点
    
    
      
      
    • OOP（Ordinary Object Pointer）表示对象实例：对象头（Mark Word + 类型指针）+ 实例字段，分配在堆中。Klass 表示类元数据：字段布局、方法、虚方法表（vtable / itable）、常量池、父类、访问标志等，JDK8+ 存在元空间。
      • 
      
    • 一个类只有一个 Klass，这个类的所有实例都通过对象头中的类型指针指向同一个 Klass。
      • 
      
    • 为什么拆开：C++ 中带虚函数的对象每个都要带一个 vptr；拆分后实例只保留数据和一个类型指针，方法分派信息只在 Klass 中存一份，对象更小，布局也可控——数据（OOP，每个对象一份）和描述（Klass，每个类一份）分离。
      • 
      
    • 体系：oopDesc → instanceOopDesc / arrayOopDesc（objArrayOopDesc、typeArrayOopDesc）；Klass → InstanceKlass（InstanceMirrorKlass、InstanceRefKlass、InstanceClassLoaderKlass）/ ArrayKlass（ObjArrayKlass、TypeArrayKlass）。
      • 
      
    • 加载类时同时在堆中创建 java.lang.Class 镜像：InstanceKlass._java_mirror 指向它，Class 对象内部也有字段反向指向 Klass；getClass()、反射拿到的都是 mirror；JDK7 起静态变量存放在 mirror 中（在堆里）。
      • 
      
    • new Person()：类未加载则先加载（InstanceKlass + mirror），再在堆中分配 instanceOop、设置 Mark Word、类型指针指向 InstanceKlass、字段零值、执行构造方法。p.say()：OOP → Klass → vtable，这就是动态分派。p.getClass()：OOP → Klass → _java_mirror。
      • 
      
    • 对象头里的"类型指针"就是 OOP 指向 Klass 的指针；开启 -XX:+UseCompressedClassPointers（默认）时占 4 字节，Klass 放在压缩类空间（Compressed Class Space，默认 1G）。
