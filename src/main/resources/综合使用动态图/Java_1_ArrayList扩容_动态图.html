    要点
    
    
      
      
    • 底层是 Object[] elementData；size 是元素个数，elementData.length 是容量。
      • 
      
    • new ArrayList() 指向共享空数组 DEFAULTCAPACITY_EMPTY_ELEMENTDATA（JDK8+ 懒加载），第一次 add 才扩到默认容量 10；new ArrayList(n) 直接分配 n。
      • 
      
    • 扩容：newCapacity = oldCapacity + (oldCapacity >> 1)，约 1.5 倍；1.5 倍仍不够就直接用所需最小容量；超过 MAX_ARRAY_SIZE（Integer.MAX_VALUE - 8）走 hugeCapacity。
      • 
      
    • 扩容方式：Arrays.copyOf 新建数组并整体复制（System.arraycopy），是 O(n) 操作，所以能预估数据量时应指定初始容量。
      • 
      
    • 对比：Vector 默认 10、扩容 2 倍；ArrayList 非线程安全。
