线程阀：闭锁、栅栏与信号量

线程阀是控制多个线程执行节奏的同步工具。CountDownLatch 让线程等计数归零，CyclicBarrier 让一组线程互相等齐再一起走，Semaphore 限制同时访问资源的线程数。

    要点
    
    
    
      
    
        
    工具作用能否复用实现
    
        
          
    CountDownLatch 闭锁计数减到 0 之前，await 的线程都阻塞。典型场景：主线程等待 N 个子任务完成一次性，不能重置AQS 共享模式，state = 计数值
    
          
    CyclicBarrier 栅栏N 个线程互相等待，都到达屏障点后一起继续，可指定到达后执行的 barrierAction可循环使用ReentrantLock + Condition
    
          
    Semaphore 信号量控制同时访问资源的线程数（限流），acquire 获取许可、release 归还许可可反复获取和归还AQS 共享模式
    
            
      
    
    
    
    
      
      
    • CountDownLatch vs CyclicBarrier：前者是一个或多个线程等其他线程（计数由别人减），一次性；后者是一组线程互相等待，可循环使用。
      • 
      
    • 其他线程阀：Exchanger（两个线程在同步点交换数据）、Phaser（JDK7，可动态调整参与者数量的多阶段栅栏）。
