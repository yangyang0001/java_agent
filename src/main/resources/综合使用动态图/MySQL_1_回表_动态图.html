回表：二级索引查到主键，再回聚簇索引取整行

InnoDB 的索引都是 B+ 树。聚簇索引（主键索引）的叶子存完整的行；二级索引的叶子只存索引列 + 主键值。通过二级索引查到主键后，如果还要其他列，就得拿主键再去聚簇索引查一次，这就是回表。

两棵 B+ 树：user(id, name, age, city)

    要点
    
    
      
      
    • InnoDB 的索引都是 B+ 树：聚簇索引（主键索引）叶子节点存完整行；二级索引（普通索引）叶子节点只存索引列 + 主键值。
      • 
      
    • 回表：通过二级索引查到主键值后，还要拿着主键到聚簇索引中再查一次，才能取到其他列。例：idx_name 中找到 name='Tom' → id=10 → 到聚簇索引查 id=10 的整行。
      • 
      
    • 代价：每条记录一次随机 IO；回表的行数多时，优化器可能直接选全表扫描。
