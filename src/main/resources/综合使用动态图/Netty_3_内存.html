内存（池化、堆外内存与引用计数）

ByteBuf 的分配方式、存储位置、生命周期是三件事：池化决定复用，heap / direct 决定存储位置，引用计数决定何时归还资源。普通 slice / duplicate 共享存储但不增加引用计数。

    概念落地边界
    池化 / 非池化是否复用内存块；池化与 heap / direct 是不同维度。
    

    Heap / Direct堆内 / 堆外存储；堆外缓冲并不意味着整个网络链路零拷贝。
    

    retain / release增加 / 减少生命周期引用；计数归零后所有共享视图不可再访问。
    

    常见问题与排查
    现象先检查什么 / 如何处理
    Direct memory 增长结合活动缓冲、分配器指标、泄漏报告与请求量排查，区分池驻留与泄漏。
    

    IllegalReferenceCountException查重复释放、发送后再使用，以及未 retain 的异步视图。
    

    线程池拒绝时泄漏提交前 retain 的引用，必须在拒绝分支释放。
    

    读写内容偶尔损坏共享切片不是线程安全对象；避免跨线程并发修改同一存储。
